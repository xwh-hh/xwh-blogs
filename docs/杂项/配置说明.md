# 配置说明
这是 xwh_hh 的 Wiki，基于 **Github Pages** + **MkDocs** + **Material for MkDocs** 主题搭建，支持 Markdown 和 LaTeX 公式。

## 作者如何添加文章？
在 `docs\所属分类\` 中新建 `标题.md`，在 `mkdocs.yml` 的 `nav` 中注册。

预览（cmd 在 my-docs 中）：
```
mkdocs-env\Scripts\activate
mkdocs serve
```

上线（cmd 在 my-docs 中）：
```
mkdocs-env\Scripts\activate
git add .
git commit -m "添加文章"
mkdocs gh-deploy
```
